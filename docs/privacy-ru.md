# Проверка перед публикацией

`tools/privacy_check.py` выполняет только чтение. Персональные шаблоны находятся
в приватном JSON вне репозитория; публичный код и тесты содержат синтетические
примеры. Адреса и имя другого автора не меняются.
Ссылки на рабочие сессии Claude также блокируются при проверке файлов и сообщений.

```sh
python3 -B tools/privacy_check.py --repo . --config "$PRIVATE_CONFIG" --history
python3 -B -m unittest discover -s tools -p 'test_privacy*.py'
```

Отчёт содержит только путь, номер строки и идентификатор правила. Код возврата
`0` означает отсутствие находок, `1` — находки, `2` — неполную проверку или ошибку.
Повреждённые архивы, превышение лимитов и неподдерживаемое сжатие не считаются
успешной проверкой. История включает все достижимые refs; недостижимые объекты,
чужие клоны, GitHub Actions и внешние документы в эту команду не входят.

Для локального запрета коммитов с повторными утечками:

```sh
git config --local privacy.configFile "$PRIVATE_CONFIG"
git config --local core.hooksPath .githooks
```

Hook `.githooks/pre-commit` проверяет содержимое индекса, имена добавляемых файлов
и подпись следующего коммита; `.githooks/commit-msg` проверяет его сообщение.
Локальный Git config и приватный JSON не публикуются.
Проверка полного дерева нужна дополнительно для ещё не добавленных экспериментов.

Новые коммиты создавайте через `tools/privacy-commit`: эта обёртка передаёт Git
`TZ=UTC`, чтобы часовой пояс машины не добавлялся в новую запись. Переданные вручную
даты Git, старые коммиты при cherry-pick и `--amend` требуют отдельной проверки.

`tools/public_metadata.py` создаёт обезличенную копию наблюдений перед сохранением
в JSON: относительные пути проекта, общее обозначение домашнего каталога,
скрытые окружение и отпечаток машины, включая полную топологию процессора.
Результаты, времена запуска, параметры solver и выбранные CPU/affinity сохраняются. Параметры эксперимента и фактические
команды/окружение дочерних процессов остаются исходными. Сохраняемые конфигурации,
которые затем выполняются, требуют отдельного преобразования путей при загрузке.
