# Идеи: обзор в ширину (10-18)

Поверхностный обзор методов, без проработки. «(есть)» — уже в `SOLVER.md`/`EXPERIMENTS.md`.
Перед реализацией сверяться с `EXPERIMENTS.md`: «цены π в поиске — шум», «одиночный перенос бесполезен» уже отброшены.

## 1. Задача как набор «зон-колонок»
- **Set packing по колонкам.** Колонка — допустимая зона: офис + выпуклое «чистое» множество сайтов. Мастер выбирает
  непересекающиеся по точкам колонки с учётом A, maxSize, навыков. Колонки бесплатно берутся из элитного пула
  и истории LNS. Мастер — свой маленький B&B или локальный поиск на графе конфликтов (MIP нет, только stdlib).
- **Merge / CMSA (Construct–Merge–Solve–Adapt).** Объединить зоны из нескольких элитных решений и точно решить
  подзадачу только на них. Кроссовер «по зонам», без перебора по сайтам.
- **Column generation с ценами.** Двойственные цены точек и офисов дают задачу поиска новой колонки, заодно получается
  оценка жёстче `bound.py`, потому что геометрия учитывается.

## 2. Геометрия
- **Optimal islands.** «Остров» — подмножество S, для которого P ∩ conv(S) = S, ровно наше условие на зону.
  Известен DP O(n³) для острова максимального веса (Bautista-Santiago и др.). Ход: при фиксированных остальных
  зонах найти лучший остров для офиса o в локальном окне, чужим точкам вес −∞. Ёмкость — ещё одно измерение DP.
- **Оболочкам не обязательно разделяться прямой**, достаточно не иметь общих точек. Значит, бывают зоны «крестом»
  или вложенные «полосы», которых не порождает ни power diagram, ни переразрез прямой. Эта часть пространства
  решений пока не исследуется; возможно, важна для inst3 (дороги против геометрии).
- **Ремонт разделимости.** Два кластера, найденные по дорожным расстояниям: убрать точки минимального веса, чтобы
  стало линейно разделимо (2 класса в 2D — вращающаяся развёртка O(n² log n)). Дешевле отброшенного
  «MIP без геометрии → ремонт».
- **Несколько прямых за раз.** Разрез тройки зон двумя прямыми или «веером» из точки; BSP глубины 2–3
  (гильотина (есть), только локально).
- **Кривой разрез.** Вместо прямой — power-граница между двумя зонами (параметризованная кривая с весом).
- **Малые инстансы (≤ 3 офиса, ~100 сайтов).** Почти полный перебор разбиений двумя прямыми, O(n⁴) с отсечениями;
  эталон для inst1/inst2.

## 3. Power diagram и оптимальный транспорт
- **Semi-discrete OT.** Веса — методом Ньютона (Kitagawa–Mérigot–Thibert) вместо координатного спуска (есть):
  сходится быстрее, точнее попадает в целевые нагрузки.
- **Unbalanced OT / generalized Laguerre diagrams.** Подходит, потому что сайты можно не брать; веса — максимум
  вогнутой функции.
- **Чёрный ящик над весами.** CMA-ES / Nelder–Mead / SPSA по (h, G) с честной целью после DP. Параметров мало: 3 на офис.
- **Centroidal power diagrams** (итерации Ллойда) — ещё один конструктор.
- **Эмбеддинг дорожных расстояний.** Classical MDS / Isomap, затем power diagram в новых координатах. Нужен как
  стартовая кластеризация: выпуклость всё равно проверяется в настоящих координатах.

## 4. Баланс нагрузки α·(max − min)
- **Параметрический подход.** Фиксируем окно [lo, hi] — задача с ёмкостями; внешний поиск по окну через min-cost flow
  с нижними/верхними границами. DP по окну (есть), flow даёт ещё назначение без геометрии.
- **Cyclic transfer / VLSN (Ahuja).** Граф улучшений: ребро o1→o2 — перенос пограничной полосы; ищем отрицательный
  цикл и цепочки выталкиваний o1→o2→o3. Выравнивает нагрузку, не трогая общее число задач. Одиночные переносы
  бесполезны (есть в журнале), а цепочки двигают сразу несколько границ.
- **Strategic oscillation.** Временно допускать перекрытие точек или нарушение A со штрафом, который динамически
  растёт. Сглаженная цель (есть) делает похожее, но только для баланса.

## 5. Навыки
- Многопрофильность проверяется назначением (есть). Можно перейти на b-matching / max-flow
  «рабочие → (офис, навык)» с инкрементальными аугментациями вместо пересчёта.
- Распределение дефицитных навыков — задача о назначении с выгодами: Венгерский алгоритм или аукцион (Bertsekas)
  по оценкам прибыли зон.

## 6. Метаэвристики и управление поиском
- **ALNS (Ropke–Pisinger).** Адаптивные веса операторов по успеху; сейчас портфель ходов фиксирован.
- **Path relinking** между элитными решениями.
- **Parallel tempering.** Потоки на разных температурах обмениваются решениями, вместо независимого отжига.
- **Другие приёмки.** Late acceptance hill climbing, great deluge, threshold accepting — обычно меньше параметров,
  чем у отжига.
- **Распределение времени.** Бандит (UCB / Thompson) по стратегиям и конструкторам с учётом признаков инстанса;
  страхует закрытые тесты лучше фиксированного портфеля.
- **Гибридные схемы из capacitated clustering.** GRASP + VNS, Clustering Search, BRKGA + local search.

## 7. Оценки и диагностика
- Оценка через column generation с частичной геометрией (только line-separable пары): покажет, сколько из 37%
  разрыва на inst3 реально достижимо.

## Что выглядит перспективнее всего
1. Optimal islands DP как ход и как генератор колонок.
2. Set packing / merge по пулу зон.
3. Зоны, не разделимые прямой (для inst3).
4. Цепочки и циклы переносов для баланса.
5. ALNS или бандит поверх уже существующих ходов.
