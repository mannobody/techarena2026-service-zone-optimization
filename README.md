# Кейс 3. Сервисные зоны (TechArena 2026)

- `solver/` — решатель (C++17, только стандартная библиотека): `solve.cpp` (main) включает части `*.h`;
  посылка склеивает их в один файл.
- `bench.py` — сборка, прогон, валидатор, таблица; `tools/` — генератор синтетики, оценки, диагностика.
- `task/` — условие, открытые инстансы, официальный валидатор, примеры организаторов.
- `submission/` — Makefile и скрипт сборки посылки в `dist/case03_cpp.zip`.
- `CLAUDE.md` — правила и команды (для людей тоже), `SOLVER.md` — схема решателя, `EXPERIMENTS.md` — журнал,
  `results/` — рекорды и посылки на NSUTS, `archive/` — исследование до условия и старый Python-решатель.

Текущая реализация — v4: генетический поиск наборов офисов, переиспользование буферов,
точная геометрия binary64, пространственный индекс и финальный B&B. Сборка использует
`-O3 -std=c++17`, стандартный лимит — 280 секунд. Состав версии и проверка соответствия
ранее подготовленному архиву, а также объединение с ALNS и кроссовером из обновлённого
main описаны в [docs/v4.md](docs/v4.md).

Экспериментальная посылка **v6** с batch-геометрией и финальными geometry/joint-DP
стадиями подготовлена отдельно: [описание и сборка](experiments/server_v6/README.md),
[ZIP для отправки](experiments/server_v6/artifacts/case03_cpp_server_v6_O3.zip). Это проверенный frozen-гибрид
из глубокого исследования; устойчивое превосходство над v4 не установлено.

```sh
python3 -m venv .venv && .venv/bin/pip install pydantic shapely   # для валидатора
python3 bench.py 60                                                # все открытые инстансы
```

В `main` — только через PR из ветки `<имя>/<задача>` (агенты: `claude/<имя>-<задача>`).
