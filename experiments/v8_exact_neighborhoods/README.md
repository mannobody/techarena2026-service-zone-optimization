Порядок: независимые малые контрпримеры и oracle → одинаковые checkpoint →
короткий полный поиск с v4/v8/all-off → заморозка → независимая проверка.
Не считать известные holdout прежнего раунда новыми данными.

Benchmark CPU: 18,19 и20,21 (разные физические ядра); сборка/подготовка:14,15.
NT=2, GCC16.2.1, -O3 -std=c++17 -pthread, последовательные блоки,
случайный порядок вариантов внутри пары, одинаковый SEED/DBG/TL.
Все измерения включают весь процесс; solver timeout и INVALID сохраняются.

Пустые офисы доминируются закрытием при неотрицательных cost/alpha.
Точность локальной окрестности не является точностью полного решателя.
Внешние SCIP/HiGHS перечислены в официальном PDF, но этот runtime использует
компактный B&B без внешних библиотек; офлайн Python-модель отдельна.
