# Серверная сборка v4

Архив: `./experiments/server_v4/artifacts/case03_cpp_server_v4_O3.zip`.
SHA256: `b4e9ace4ed6cffe53b932bb1d10f7ecdfdcc4170458afaf05e16b3068ebae953`.

Внутри `main.cpp` и `Makefile`. `make build`: `g++ -O3 -std=c++17 -o solution main.cpp`.
`make run`: `./solution`. Default280 секунд, автоматический выбор до16 доступных потоков.
Только instance.json → solution.json, без внешних библиотек, сети и межтестового состояния.
GNU unsigned __int128 применяется в точном геометрическом предикате.

Объединены:
- v3: genetic office warm start, worker DFS, reuse буферов Fast/hull/workers/warm,
  инкрементальные структуры и финальный добор;
- geometry_islands: точные предикаты binary64 и пространственный индекс всех входных точек;
- boundary_beam: финальный монотонный B&B по24 сайтам для N≤1500, только в оставшееся
  время после основного поиска; новый бюджет у основного поиска не отнимается;
- дополнительное переиспользование массива прибыли в capacity-bound B&B вместо
  выделения vector в каждом узле.

Короткие constraints из Python/SCIP и отрицательные island-эксперименты не включены.
Замена DP исследуется отдельно и не меняет зафиксированный v4.

Исходник: `artifacts/package/main.cpp`; бинарник: `artifacts/package/solution`.
Сборка: `build.py`; проверки: `check.py`, `oracle.py`; результаты: `logs/package60/results.json`,
`logs/oracle.json`; итоговый статус и hashes компонентов: `MANIFEST.json`.
Тесты полного solver: внутренний лимит60 с, конкурсные имена, официальный валидатор.

Это объединённый кандидат для серверной проверки, не доказанно лучший на скрытых тестах.
Ранее exact+grid имел худшую парную регрессию−10.875% при небольшом положительном
среднем; взаимодействие с B&B нельзя предсказать сложением результатов компонентов.
Предыдущие ZIP сохранены; основной solver не изменён.
