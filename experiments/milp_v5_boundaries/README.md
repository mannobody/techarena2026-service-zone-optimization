# v5.2 regions — экспериментальная сборка

- Сборка: `make build` (`g++ -O3 -std=c++17 -ldl`), запуск: `make run`.
- Только instance.json → solution.json. Default 280 с; проверено с TL=60, NT=2.
- HiGHS загружается динамически; нужна доступная libhighs.so/.so.1 с 32-bit HighsInt. Без неё работает native fallback.
- `REGION=0` отключает новую стадию; `MIP=0` отключает обе MILP-стадии.
- Полный новый A/B против v5: mean +1.2517%, median +0.0025%, worst -0.9135%; 60/60 VALID, package 26/26 VALID.
- Собственное улучшение региональной стадией: 22/30. Max wall кандидата: 60.199 с при TL=60; таймер библиотеки мягкий.
- v4/v5 и solver/ сохранены; v5.2 поставляется отдельным пакетом.

Среднее положительное, но медиана близка к нулю: существенную часть среднего дают крупные выигрыши на отдельных входах/seed. Регрессии сохраняются, поэтому кандидат остаётся экспериментальным, без заявления устойчивого превосходства.
