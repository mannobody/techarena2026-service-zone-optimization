# Исследование Service Zone Optimization: две лаборатории и интеграция

**Статус: экспериментальный гибрид не принят вместо v4.** На независимом
TL280 holdout среднее−0,1765%, худшая пара−2,0007%. Полезные операторы найдены
и проверены, но устойчивое превосходство полного алгоритма не доказано.

База сравнения — точная замороженная серверная v4, не объединённый модульный
solver. Кандидат и результаты исследования хранятся отдельно.

## Реализация

`integration/src/hybrid_frozen.cpp` — самостоятельный замороженный кандидат на
базе server v4 с минимальным batch, исправлением сигнатуры закрытого офиса,
финальным геометрическим проходом и joint count/load DP. Defaults новых хвостов
в этом кандидате включены; в рабочем модульном solver они остаются opt-in.

[Экспериментальный ZIP](integration/artifacts/case03_cpp_v4_deep_hybrid_experimental_O3.zip)
содержит main.cpp и Makefile, O3/C++17, TL280. Внешних MILP-библиотек, сетевых
обращений и сохранённых стартов нет. Его статус определяется полными итоговыми
сравнениями; локальный операторный выигрыш не является основанием для замены v4.

## Воспроизводимость

`shared/BASELINE_READY.json` фиксирует source/binary/compiler базы.
`integration/FINAL_FREEZE.json` и `HOLDOUT_PREREGISTRATION.json` фиксируют
кандидата и проверку до генерации новых данных. Каждый каталог полных прогонов
содержит MANIFEST, все исходные строки результатов и COMPLETE. Ошибки и
прерванные серии сохраняются отдельно, без подмены успешными checkpoint.

Основные диапазоны generator seed: geometry711000+, search721000+,
integration731000+, holdout751000+. Каждая пара алгоритмов использует одинаковый
вход, solver seed, NT=2, общий TL и ту же CPU-пару. Варианты внутри блока
перемешаны. Файлы прежних исследований не удалены и не переписаны.

На неоднородной машине отдельные серии не должны пересекаться по CPU. Lock-файлы
координатора локальны каталогу серии; межсерийное разделение обеспечивается
явной передачей CPU между лабораториями. Скрипты интеграции фиксируют эти
зависимости. Глобальные частоты и энергопотребление машины не изолированы.
