Hypotheses (registered before generating development inputs):

1. **Batched exact geometry:** frozen v4 rebuilds coverage after every removed hull point and every rollback insertion. Deferred rebuild of each changed office once per removal transaction/rollback should give exactly identical final state, with no changed predicate. Measure fixed-work transactions plus TL-quality separately.
2. **Adaptive operator allocation:** move classes differ strongly in productive gains per CPU-second. Port ALNS alone from merged implementation, keeping half baseline probabilities; distinguish it from geometry batching and crossover.
3. **Persistent search trajectories:** worker rebuilds high-ranked office sets each visit and loses non-global local optima. Keep best verified state per candidate origin, continue it on revisits; same chunk lengths and elite-selection probabilities. Unlike previous GWW, no shortening chunks or cloning the entire population.
4. **Wide portfolio without shortened search:** decouple constructor-start counter from global-elite rounds and include rank>=6 while preserving original 0.12TL chunks. Previous cover changed both coverage and chunk duration; test this isolated alternative.
5. **Exact worker-certificate memoization:** greedy/DFS repeatedly solve identical office×required-skill states. Cache successful certificates keyed by the complete demand bitstring (no hash-only acceptance), bounded per thread, never cache bounded DFS failures. Test multiskill fixed work and wall-quality.
6. **ALNS + persistent trajectories interaction:** exploitation of productive neighborhoods may benefit when trajectory state is retained. Compare components and combined version, rather than sum marginal gains.
7. **Long-run basin diagnosis:** compare final office masks, count/task profiles, and 60 versus 280/600-second runs. If same masks plateau, rank changes are unlikely to help; if strong masks disappear, quantify gap and persistence.
8. **Reheat from retained basin:** if archive repeatedly returns same local optimum, use alternating ruin scale and a restrained temperature restart while retaining certificate; test only after baseline archive is understood, do not tune on holdout.
